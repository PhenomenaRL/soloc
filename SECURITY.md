# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security vulnerabilities (this matters
especially for anything exploitable in `soloc-server`, which listens on the network).

Report privately via GitHub's [private vulnerability reporting](https://github.com/PhenomenaRL/soloc/security/advisories/new)
(Security tab → "Report a vulnerability").

You can expect an acknowledgement within a few days. Please include reproduction
steps and an assessment of impact if you can.

## Supported versions

soloc is pre-1.0; only the latest release (and `main`) receive fixes.
