# Local texture overrides

Planet textures load from the jsDelivr CDN by default
(`jeromeetienne/threex.planets`). To run fully offline — or swap in
higher-resolution maps — drop files into this folder using these exact names;
local files always win over the CDN:

sunmap.jpg · mercurymap.jpg · mercurybump.jpg · venusmap.jpg · venusbump.jpg ·
earthmap1k.jpg · earthbump1k.jpg · earthcloudmap.jpg · earthcloudmaptrans.jpg ·
moonmap1k.jpg · moonbump1k.jpg · marsmap1k.jpg · marsbump1k.jpg ·
jupitermap.jpg · saturnmap.jpg · saturnringcolor.jpg · saturnringpattern.gif ·
uranusmap.jpg · neptunemap.jpg · galaxy_starfield.png

Any equirectangular map with the same filename works (e.g. the 2k/8k sets from
solarsystemscope.com, CC BY 4.0).

Default texture credit: James Hastings-Trew — planetpixelemporium.com.
Free to use in projects; not to be redistributed as standalone textures.
